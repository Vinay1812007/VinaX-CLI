# Changelog

Milestone progress before the first npm release. Once `vinax` is published, per-release notes are
generated by changesets in `packages/cli/CHANGELOG.md`.

## Unreleased

### M2: Terminal UI (2026-09-23)

- **Interactive mode** is built with Ink 7. `vinax` starts it, and `vinax "prompt"` starts it
  with a first prompt. It needs a real terminal; in scripts, use `vinax -p`.
- **First-run setup** has four steps: theme with a live preview, provider, API keys (each checked
  live, with keys from environment variables reused), and a default model chosen from the
  provider's live catalogue. The folder trust prompt remembers its answer for the folder and
  everything inside it.
- **Welcome panel** shows the VinaX wordmark, version, folder, model and provider, plus three
  random tips.
- **Input box:**
  - multi-line editing (`\`+Enter, Shift+Enter via the kitty keyboard protocol, Option/Alt+Enter)
  - bracketed paste, with large pastes collapsed to a placeholder
  - per-project history (↑/↓) and reverse search (Ctrl+R)
  - readline-style editing keys
  - prompts typed while a reply streams are queued
- **Streaming Markdown** has its own renderer covering headings, lists, task lists, tables, block
  quotes and highlight.js code blocks. Finished blocks move into scrollback as they complete, so
  long answers don't flicker.
- **Activity indicator:** animated glyph, rotating status words, elapsed time, approximate
  tokens and `esc to interrupt`. Rate-limit waits are shown in place.
- **Footer:** mode (Shift+Tab cycles default → auto-accept edits → plan), active model, and how
  much of the context budget is used, capped by tokens-per-minute on Groq. Fallback and retry
  notices appear there too.
- **Keys:** Esc interrupts and keeps the partial answer (the model sees it was cut off). Ctrl+C
  clears the prompt, and pressing it twice within 2s exits. Ctrl+D exits. Ctrl+O shows turn
  details and live rate limits. `?` shows every shortcut.
- **Themes:** dark, light and colour-blind friendly (Okabe–Ito). `NO_COLOR` switches to a
  monochrome UI.
- **Conversations:** the core `ChatSession` keeps multi-turn history. The new `theme` setting is
  also added.
- **Fixed:** a stream cut off by an abort was treated as a finished answer, because the SDK ends
  the iteration quietly. It's now reported as interrupted.
- **Fixed:** the process could linger after exit while idle HTTP keep-alive sockets stayed open.
- **Deferred:**
  - The optional gateway login step of onboarding moves to M6, where the gateway is built.
  - The Esc Esc rewind picker moves to M3, with checkpoints.
  - `/vim` moves to M4, with slash commands.

### M1: Core (2026-09-23)

- pnpm monorepo: `packages/core` (UI-free), `packages/cli` (`vinax`), `packages/testkit`, with
  strict TypeScript, ESLint (typed, strict), Prettier, Vitest and Changesets.
- Settings: zod-validated, merged from user, project, local and CLI layers. Unknown keys produce
  warnings and invalid values produce errors that name the key. `.vinax/settings.local.json` is
  added to `.gitignore` automatically.
- API keys: environment variables first, then the OS keychain (`@napi-rs/keyring`), then a 0600
  credentials file. Keys are verified live before they're stored.
- Providers: Groq and OpenRouter through the official `openai` SDK with per-provider `baseURL`,
  streaming and usage reporting. Model catalogs come from `/models` and are cached for 24h.
  Configured models missing from a catalog are skipped with a warning.
- Rate limits: Groq and OpenRouter rate-limit headers and `retry-after` are parsed into a ledger,
  with a local requests-per-minute window. Requests that can't fit a model's tokens-per-minute
  budget are never sent to it.
- Router: the fallback chain uses a pre-flight budget check, a short wait-or-skip decision,
  exponential backoff with jitter for transient errors, and one-line fallback notices. It never
  falls back mid-stream.
- `vinax -p`: piped stdin, `--output-format text|json|stream-json`, `--model`, and meaningful
  exit codes (0/1/2/130).
- `--verbose` writes a JSON-lines debug log with API keys redacted.
- `vinax config list|get|set|unset|keys|set-key|remove-key`.
